# 记账统计

本插件只读取指定文件夹中的每日记账 Markdown，正文逐笔记录是唯一统计来源；frontmatter `total` 只参与核对，`.base` 与 `.duowei` 不会计入。

## 安装与使用

当前目录已经是可安装的 Obsidian 插件目录。构建后确保 `main.js`、`manifest.json`、`styles.css` 位于 `.obsidian/plugins/ledger-statistics/`，然后在“设置 → 第三方插件”中启用“记账统计”。使用左侧栏饼图图标或命令“打开记账统计”进入。

也可以从 GitHub Releases 下载最新的 `ledger-statistics-v*.zip`，解压到 Vault 的 `.obsidian/plugins/ledger-statistics/` 目录后启用插件。

默认打开本月总览；顶部筛选在六个视图间保留。时间筛选提供“工资日”，按每月15日至下月14日计算；当前周期尚未到14号时，结束日期取今天。时间选择器旁的“上一期”和“返回”按钮会按照当前时间类型切换日期：工资日切换工资周期，本月或上月切换月份，今天切换日期，今年切换年份；自定义期间不启用周期切换。点击指标、图表、分类行或日期会进入对应明细。默认“消费支出”会排除设置中配置的 `债务/还款`，切换到“全部支出”可纳入。排除后的结果只是配置口径，并不代表已经人工核实的真实消费额。日均的分母是所选范围内实际存在日记账文件的日期数，缺少文件的日期不按零消费处理；有文件但当前口径金额为零的日期仍进入分母。

设置中的“每日预算”用于总览的“今日预算”液体进度条。预算卡片固定统计本地今天的支出，不受总览的日期、分类和关键词筛选影响；“预算分类”默认统计全部分类，包括 `债务/还款`，选择具体分类后只统计该分类。“今日预算星标口径”可以选择包含或排除星标支出，并统一作用于今日已花、当前工资周期支出和 Bark 提醒。预算金额下方会按31天估算月支出，并显示从本月15日至今天的当前工资周期支出；预算未设置时显示提示，超出预算时显示超支金额。填写“Bark 推送地址”后，当前预算口径首次达到或超过预算时会发送一次提醒，每个自然日最多一次；地址只保存在本地设置中。

总览底部会显示“星标大额支出”面板。它不会自动按金额判断，而是汇总顶部所选时间范围内、由你在明细中手动标记为星标的记录；桌面端可右键记录，移动端可长按记录，在菜单中选择“标记为星标”。星标状态保存在插件本地设置中，不会修改原始 Markdown 账目。

## Lieflat Charts 视觉体系

界面采用纸张灰、墨黑与七级灰阶构成的单色系统，保留宽圆角卡片、细线图形、结论式标题和明确来源行。分类条形图、环形图、趋势折线/面积图和对比图分别基于 Lieflat Charts 的 F5、F4、F2/F3、F12 图形语法实现，并针对 Obsidian 的点击下钻、中文标签、深色主题和移动端触摸操作进行了适配。所有图形均由插件本地生成 SVG，不加载 Lieflat 页面或任何远程资源。

## 移动端

- 筛选区默认收起为一行摘要，点击后展开；当前日期、口径和分类无需展开即可确认。
- 开始与结束日期合并在同一个双列日期组中，六个视图入口保持单行可见。
- 总览指标使用 2×2 卡片布局；分类刻线、趋势图和期间对比使用独立的移动端图形，不再按比例缩小桌面 SVG。
- 较长趋势图支持横向触摸滚动，明细使用卡片列表，日历使用逐日单列列表。
- 所有主要控件保持至少 44px 的触摸高度；手机端不依赖悬停交互。
- 从图表、分类或日历下钻到明细时会保留原筛选条件；点击明细顶部的“返回上一级”即可回到原本月或原期间。
- 明细卡片的“打开来源”固定在卡片底部操作区，避免与备注内容混排。
- 移动端滑到底后停留；从底部重新上拉时显示进度，拉动约 100px 后提示“松手切换”。松手才进入下一个视图，未达到阈值或收回手势则回弹取消。最后一个视图不循环跳转。

## 口径与限制

- 金额全程使用整数分；不修改账目，不自动纠错或重分类。
- 文件日期优先使用有效的 frontmatter `date`，缺失或异常时回退到文件名日期，同时显示诊断。
- frontmatter `date` 支持 `YYYY-MM-DD` 和 Obsidian 常见的 ISO 日期时间；日期时间按其中明确写出的日历日期归档，不进行时区换日。
- 只解析“今日消费记录”标题后的列表项，直到下一个标题；空白列表项被安全忽略。
- 无法解析的非空记录、日期异常以及正文与 frontmatter `total` 不一致都会显示文件、行号（适用时）和原因。
- 自定义比较按用户选择的完整区间；当前月与上月默认按截至今天的同期天数比较。
- 对比基期为零且本期非零时显示“新增”，两期均为零时显示“—”，不会输出无穷大百分比。
- 原始笔记定位会尝试跳到对应行；Obsidian 不同版本或移动端可能只保证打开文件。
- 图表为本地原生 SVG，不依赖 CDN、远程字体或外部服务。
- Vault API 的新增、修改、删除和重命名事件只重算受影响文件；修改记账文件夹或手动刷新时才重新扫描。
- 已完成桌面端和移动端模拟/窄屏验证；真实手机设备尚未验证。

## 隐私与兼容性

插件运行时不访问网络，不使用 CDN、远程字体、Node `fs`、Electron 或绝对 Windows 路径。账目始终留在本地 Vault。`manifest.json` 设置 `isDesktopOnly: false`，界面使用 Obsidian 原生主题变量、触摸尺寸控件和窄屏单列/卡片布局。
