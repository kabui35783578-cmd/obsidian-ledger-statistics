# 记账统计

本插件只读取指定文件夹中的每日记账 Markdown，正文逐笔记录是唯一统计来源；frontmatter `total` 只参与核对，`.base` 与 `.duowei` 不会计入。

## 安装与使用

当前目录已经是可安装的 Obsidian 插件目录。构建后确保 `main.js`、`manifest.json`、`styles.css` 位于 `.obsidian/plugins/ledger-statistics/`，然后在“设置 → 第三方插件”中启用“记账统计”。使用左侧栏饼图图标或命令“打开记账统计”进入。

也可以从 GitHub Releases 下载 `ledger-statistics-v1.0.0.zip`，解压到 Vault 的 `.obsidian/plugins/ledger-statistics/` 目录后启用插件。

默认打开本月总览；顶部筛选在六个视图间保留。点击指标、图表、分类行或日期会进入对应明细。默认“消费支出”会排除设置中配置的 `债务/还款`，切换到“全部支出”可纳入。排除后的结果只是配置口径，并不代表已经人工核实的真实消费额。日均的分母是所选范围内实际存在日记账文件的日期数，缺少文件的日期不按零消费处理；有文件但当前口径金额为零的日期仍进入分母。

## Lieflat Charts 视觉体系

界面采用纸张灰、墨黑与七级灰阶构成的单色系统，保留宽圆角卡片、细线图形、结论式标题和明确来源行。分类条形图、环形图、趋势折线/面积图和对比图分别基于 Lieflat Charts 的 F5、F4、F2/F3、F12 图形语法实现，并针对 Obsidian 的点击下钻、中文标签、深色主题和移动端触摸操作进行了适配。所有图形均由插件本地生成 SVG，不加载 Lieflat 页面或任何远程资源。

## 构建

```powershell
npm install
npm run verify
```

## 口径与限制

- 金额全程使用整数分；不修改账目，不自动纠错或重分类。
- 文件日期优先使用有效的 frontmatter `date`，缺失或异常时回退到文件名日期，同时显示诊断。
- 只解析“今日消费记录”标题后的列表项，直到下一个标题；空白列表项被安全忽略。
- 无法解析的非空记录、日期异常以及正文与 frontmatter `total` 不一致都会显示文件、行号（适用时）和原因。
- 自定义比较按用户选择的完整区间；当前月与上月默认按截至今天的同期天数比较。
- 对比基期为零且本期非零时显示“新增”，两期均为零时显示“—”，不会输出无穷大百分比。
- 原始笔记定位会尝试跳到对应行；Obsidian 不同版本或移动端可能只保证打开文件。
- 图表为本地原生 SVG，不依赖 CDN、远程字体或外部服务。
- Vault API 的新增、修改、删除和重命名事件只重算受影响文件；修改记账文件夹或手动刷新时才重新扫描。
- 已完成桌面端和移动端模拟/窄屏验证；真实手机设备尚未验证。

## 隐私与兼容性

插件运行时不访问网络，不使用 CDN、远程字体、Node `fs`、Electron 或绝对 Windows 路径。账目始终留在本地 Vault。`manifest.json` 设置 `isDesktopOnly: false`，界面使用 Obsidian 原生主题变量、触摸尺寸控件和窄屏单列/卡片布局。
