# 单分类分析：Lieflat 模板与数据契约

参考正本：https://github.com/larashero3-dotcom/lieflat-charts

沿用本插件已使用的 Wire 色板、字体、24px 圆角卡片和既有图表组件，不引入另一套界面风格。图表保留标题、副标题、真实单位与来源行；证据列表使用透明行底和细线，不套用主题默认按钮外观。

| 信息 | 候选比较 | 最终实现 |
| --- | --- | --- |
| 用途构成 | L14 Hundred Field 需要百分比取整；L5 Radial Convergence 不适合高笔数及混合备注；F4 Tick Donut 保留完整占比和长尾图例 | 复用 `ui.ts` 的 F4；金额分组互斥，无法识别的用途保留，混合付款不拆分 |
| 金额分布 | F1/F5 只表示汇总，不表示分布；F14 等宽分箱需要额外业务档位；原始金额可直接计算五数概括，符合 F15 直接选用条件 | `category-charts.ts` 从 basics-gallery.html 的 F15 Tick Box 移植线性轴、须线、胶囊箱体、中位数横档及空心离群点；每个离群点可打开真实交易 |
| 重复项目变化 | L2 只能给单期排序；F6 长备注拥挤；F12 横向对比适合最多六组备注和两期金额 | 复用 F12 Dumbbell Queue；上期须可比，缺失时退回原始备注记录列表，不将未知视为零 |
| 星期日均 | L3 是长日序列，不是七类星期；L10 要实际时刻和事件规模；F1 可编码七个星期的金额 | 从 basics-gallery.html 的 F1 Rung Bars 移植：固定金额单位、每五档点标、零起点，最后不足单位的档位用虚线，标注精确金额 |
| 最高十笔 | L2 需要可数单位和短类目；L12 需要真实多对一归属；F5 横向刻线队列可保留长备注与日期 | 复用 F5 Tick Rows，按用户要求扩为十行并增加行距和日期；每根完整刻线表示固定金额，末根按余数绘制，点击打开原始账目 |

体系内不重复图型；走势仍复用 F2 Hairline Line。单笔金额、商品价格、笔数和购买数量分别解释；统计离群不判定浪费或消费失控。窄屏使用同一组件的适配布局，保留图表单位与精确数值。
