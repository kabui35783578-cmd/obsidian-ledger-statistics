# 资产页设计依据

v3.0.5 的首页布局来自用户提供的资产页面截图。按用户后续明确要求，只复现排版，UI 保留插件现有纸灰、炭黑、圆角、无阴影卡片、字体与柔和彩色图表风格。

首页首先展示一张总览面板：总资产标题和隐私按钮在左，排除固定资产开关在右；下方依次为总金额、更新日期与刷新行情、同一行的净资产和负债率。总览面板内嵌资产对比区，包含“相比前一天”、资产月历入口、总资产与总负债变动，以及流动资金、固定资产、投资理财、应收款、负债五类变动柱图。按用户要求使用前一个自然日快照，缺失该日记录时不使用更早快照代替。所有增减均由代码计算；红色箭头方向表示上涨或下降，不代表投资收益。

总览下方为资产组成。首页 SVG 用净资产、总资产、分类及淡色账户流线呈现参考图结构，金额以带宽表达；点击分类或放大图标进入包含所有账户和持仓的完整桑基图。首页不显示缩放按钮和英文来源行。添加持仓、更多入口保留在图表下方，更多中保留账户管理及其他原有操作。负债对比项可打开负债管理。

资产月历每一天的箭头和选中日期详情采用与首页一致的前一自然日口径。无可比快照显示破折号，详情解释“暂无可比记录”；估值不完整也不推测方向。隐藏金额会隐藏数值、涨跌方向和变动柱高度。固定资产排除开关同时应用于对比两日，避免口径变化产生虚假增减。

完整桑基图延续此前实现的四段金额流、账户与持仓详情、键盘查询和触摸缩放拖动。既有柔和彩色方案为青绿 #76A69A、蓝 #7C9CBF、麦黄 #C6B16B、紫 #A895BD、橙 #D69B89，流线起点透明度 0.44、终点 0.24、节点 0.72。资产组成仍为透明底。颜色用于分支辨识，带宽用于金额编码。

主页图表预览不接管页面滚动；放大视图保持独立正方形弹窗、触控板和双指缩放。资产管理等二级弹窗保留现有纸灰面板、细分隔线与紧凑账户卡片。所有图形本地生成，无新增网络字体、图表服务或运行时依赖。
