# 资产页设计依据

参考：https://github.com/larashero3-dotcom/lieflat-charts

资产总览采用一张反色总资产主卡和三张浅灰指标卡，取消整块灰色面板。总金额、隐私按钮与行情刷新收在主卡内；排除固定资产位于区块标题旁。窄屏下主卡与指标组上下排列，月度比较与资产月历继续显示在独立的底部行。

账户列表和添加账户入口统一收在“更多 → 资产管理”弹窗中，点击账户卡片管理余额与持仓；主页保留添加持仓、更多、资产总览和桑基图。账户卡片继续遵守隐藏金额状态，资产管理弹窗与其他弹窗共享账户类别颜色。

二级弹窗使用无阴影的纸灰面板和细分隔线，标题、表单与按钮保持同一文字层级；管理入口为图标、文字、箭头组成的菜单项，圆角 12px。账户卡片改为名称与说明在左、余额在右的紧凑布局；手机使用单列，桌面使用双列。弹窗阴影与边框使用局部强制样式，防止宿主主题的浮层样式覆盖插件风格。

放大视图使用独立的正方形弹窗，边长由视口宽高共同约束。弹窗恢复不透明纸色背景，主页面图表卡片仍为透明底。放大视图不创建加减及百分比按钮，继续支持双指缩放、单指拖动和触控板缩放；资产月历弹窗保持原有尺寸和操作。

资产主页的桑基图容器允许纵向滚动继续传递给页面，避免图表没有可滚动内容或到达边界时，鼠标滚轮被困在图表中；单指纵向滑动使用浏览器原生滚动，横向拖动与双指缩放仍由图表处理。弹窗继续隔离滚动，避免拖动图表时带动背景页面。

页面延续插件已有的纸灰、炭黑、圆角、无阴影卡片和编辑式标题。总览压缩为总资产与三个指标的并列布局，账户操作保留原功能。图表使用本地 SVG，未引入网络字体、图表服务或运行时依赖。

资产组成保留原有四段桑基图，主力模板比较：L5 Radial Convergence 以归属为主，不能保留金额带宽；L12 Type Colonnade 擅长带名单的归属，不能表达现有分段金额流；F13 Nested Treemap 可以展示层级与份额，但会替换用户明确要求保留的桑基图。因此采用 `templates/glance-gallery.html` 的 G22 Aggregate Sankey（卡内标题 `Channels pour into plans`）作为视觉结构依据：保留贝塞尔缎带、金额线性比例、连续累加的节点与流线、触摸和键盘查询。调整节点圆角、字重、字号、标题、副标题与来源行，不改变金额编码。

按用户明确提出的“多加几个颜色、加入透明度、不要实底”，桑基图采用一套自定义柔和彩色方案：青绿 `#76A69A`、蓝 `#7C9CBF`、麦黄 `#C6B16B`、紫 `#A895BD`、橙 `#D69B89`。类别与账户标识使用一致颜色，持仓按账户内顺序循环色板，投资账户未分配资金使用橙色。流线沿节点间渐变，起点不透明度 0.44、终点 0.24，节点 0.72；卡片背景透明，只保留细边界与插件原有文字颜色。该透明度与自定义色板依据用户要求覆盖 skill 默认的实色和内置色板限制，并非仓库的原厂色彩模式。颜色用于分支辨识，不编码金额大小；数量始终以带宽表达，账户名称和金额独立标注。渐变 ID 在各图之间唯一，避免放大弹窗与主图的渐变引用互相影响。隐藏金额同时隐藏可访问标签中的金额。
